# Новый скетч с нуля: NanoBldcClean

[Открыть скетч](firmware/NanoBldcClean/NanoBldcClean.ino).
Все непустые строки `.ino`, включая директивы, скобки и шапку, прокомментированы
по-русски. Из предыдущих версий использована распиновка; настройки и алгоритм выбраны
заново. Прежние скетчи сохранены отдельными файлами.

## Выбор платы

**Сам файл `.ino` не может переключить плату Arduino IDE:** IDE выбирает компилятор,
процессор и параметры до обработки кода. В начале скетча стоят проверки Nano,
ATmega328P и частоты 16 МГц. Они остановят неподходящую сборку с русским сообщением.

Для **Arduino CLI** рядом со скетчем находится `sketch.yaml` с `default_profile: nano`.
Он задаёт плату `arduino:avr:nano:cpu=atmega328` и ядро Arduino AVR 1.8.6. Из корня
распакованного репозитория:

```sh
arduino-cli compile firmware/NanoBldcClean
arduino-cli upload --port COM3 firmware/NanoBldcClean
```

Порт COM3 заменить своим. Для Nano со старым загрузчиком использовать профиль:

```sh
arduino-cli compile --profile nano_old firmware/NanoBldcClean
arduino-cli upload --profile nano_old --port COM3 firmware/NanoBldcClean
```

Нужна установленная Arduino CLI с поддержкой профилей. Саму CLI не устанавливает
скетч; команда сборки профиля может потребовать загрузки пакета ядра из интернета.
Профили подготовлены, но запуск Arduino CLI в этой среде не проверен: сборка здесь
выполнена AVR GCC с установленным ядром Arduino AVR 1.8.7.

В **Arduino IDE** выбрать вручную **Arduino Nano → ATmega328P**. Для старого загрузчика
выбрать **ATmega328P (Old Bootloader)**. Профиль CLI не переключает меню IDE.

## Подключение

| Назначение | Вывод |
|---|---|
| Верхние ключи У / В / Ш через NPN | D7 / D4 / D2 |
| Нижние ключи У / В / Ш | D11 / D10 / D9 |
| Делители фаз У / В / Ш | A3 / A2 / A1 |
| Виртуальная нейтраль | A0 |
| Нейтраль на положительном входе компаратора | A0 через 1 кОм на D6 |
| Потенциометр | A4 |
| Кнопка реверса на GND | D8 |

Верхние и нижние ключи включаются высоким логическим уровнем. Все измерительные
входы должны оставаться в пределах 0..5 В, включая выбросы. D6 — вход без подтяжки.
Скетч рассчитан на классическую Nano 5 В / 16 МГц, не Nano Every.

## Как работает новый вариант

* После включения мост отключён; сначала ручку необходимо повернуть в ноль.
* Увеличить ручку немного выше нуля и послать `t`: позиционирование 600 мс, затем
  принудительный разгон от сектора 100 мс до 20 мс. Длительность каждого следующего
  сектора сокращается на 1%. Стартовое заполнение — 54/255, примерно 21%.
* На конечной частоте проверяется ЭДС свободной фазы. Требуются девять подряд
  подходящих секторов; после 90 безуспешных секторов мост отключается.
* После захвата момент коммутации задаётся пересечением ЭДС с нейтралью и задержкой
  в половину периода сектора: это 30 электрических градусов. Период определяется
  медианой трёх последних интервалов между пересечениями.
* ШИМ нижних ключей — аппаратный, около 31 кГц. Знак компаратора читается внутри
  включённого участка, проверяется по двум снимкам счётчика и уровню выхода порта.
* После захвата ручка меняет заполнение плавно, от 54/255 до 140/255. Это регулировка
  **мощности**, не замкнутый регулятор заданных оборотов. Минимум ручки отключает мост.
* `s` выключает мост. `r` или кнопка тоже сначала выключают мост и меняют направление
  **следующего ручного пуска**. Автоматического перезапуска нет.
* После любой остановки выдерживается минимум 6 секунд и требуется возвращение ручки
  в ноль. Оператор должен убедиться в полной остановке: пауза не является датчиком
  неподвижности ротора.

## Команды

Монитор порта: **115200**. Команды однобуквенные; окончание строки можно использовать,
но оно не требуется. Строчные латинские буквы:

| Команда | Действие |
|---|---|
| t | Пуск с обратной связью после предварительного нуля ручки |
| j | Двенадцать медленных шагов по 250 мс без компаратора, затем отключение |
| o | Новый медленный разгон без компаратора, 3 секунды на конечной частоте, затем отключение |
| + / - | Изменить стартовый ШИМ на 6 отсчётов, только в ожидании, без автоматического пуска |
| s | Отключение |
| r | Отключение и смена направления следующего пуска |
| q | Сведения при отключённом мосте |
| d | Таблица частоты и оборотов за последние шесть секунд выбега, после завершения записи |
| e | Инверсия ожидаемого перехода ЭДС, только после выбега, в состоянии ожидания |

Если пуск не происходит, сначала ручку в ноль, дождаться окончания паузы, затем
немного увеличить ручку и послать t. Для первого теста не ставить ручку на максимум.

Коды остановки:

| Код | Причина |
|---|---|
| 0 | Ручная остановка, реверс или ноль потенциометра |
| 1 | Недопустимое опоздание коммутации |
| 2 | Потеря пересечения ЭДС |
| 3 | Скачок периода пересечений более чем на 30% |
| 4 | Выход периода за настроенный диапазон 1800..50000 мкс |
| 5 | Слишком позднее подтверждение ЭДС для очередной коммутации |
| 6 | Неудачный захват обратной связи |

## Если вместо разгона вибрация и код 6

Код 6 означает отсутствие захвата ЭДС, а не подтверждённый разгон. Уменьшение требований
к захвату не заставит неподвижный ротор вращаться. В обновлённой версии сначала
проверяется движение без обратной связи.

1. После прошивки: ручку в ноль, затем немного увеличить, послать **j**.
   После позиционирования ротор должен делать последовательные перемещения в одну
   сторону. Допустима ступенчатость; качание в одной точке не является нормальным
   результатом. Тест сам выключит мост после 12 шагов. При большом токе — сразу s.
2. Если j не даёт последовательного движения, **не переходить к длительным пускам o**.
   Проверить напряжения на всех трёх фазах и работу каждого плеча. Причина может быть
   в мощности, сопоставлении выводов ключам, неисправном плече или фактических фронтах.
   Все шесть управляющих сочетаний должны давать разные последовательные положения.
3. Если виден слабый, но правильный ход и ток находится в допустимых для двигателя и
   ключей пределах, дождаться выбега и состояния ожидания, послать один **+**: 54→60
   из 255, то есть примерно 21→24%. Затем повторить j. Увеличивать мощность только
   под контролем тока; не увеличивать предел БП, пока причина ограничения не ясна.
   Команда q показывает стартовый ШИМ; знаки + и - ограничены 42..90 из 255.
   Перезапуск платы возвращает 54. Вращение ручки пока ещё не регулирует пусковой ШИМ.
4. При последовательных шагах: ручку в ноль, дождаться не менее 6 секунд и полной
   остановки, немного увеличить ручку и послать **o**. Выполнится медленный разгон
   примерно за 8 секунд, затем 3 секунды на конечной частоте и отключение. Код 0
   означает окончание теста, а не подтверждение фактического вращения ротора.
5. Только если o действительно вращает двигатель, повторить запуск командой t.
   Если разгон ровный, а t заканчивается кодом 6, дальше проверять сигнал нейтрали,
   каналы измерения и полярность e по осциллограмме. В тестах j и o компаратор отключён,
   команда e на их результат не влияет.

Длительность позиционирования увеличена с 320 до 600 мс, начальный сектор — с 24 до
100 мс, конечный — с 5 до 20 мс. При двух парах полюсов ротора начальная расчётная
скорость поля снижена примерно с 208 до 50 об/мин; это не измеренная скорость ротора.
Стартовое заполнение по умолчанию не увеличено. Новые параметры — гипотеза для
стендовой проверки, не доказанное решение конкретной аппаратной проблемы.

## Измерение частоты и оборотов при выбеге

После завершения o, j, ошибки t, команды s или отключения по нулевой ручке:

1. Сначала снимаются все шесть управляющих сигналов, включается АЦП и начинается
   шестисекундная запись. Первые 4 мс исключены из поиска периодов из-за переходных
   процессов. Во время записи мост не включается.
2. Измеряются A3 (фаза У) и A0 (нейтраль), после переключения канала первое чтение
   отбрасывается. Примерно каждые 1,4–1,6 мс получаем знак У−N. Два однонаправленных
   перехода через нейтраль с гистерезисом определяют полный электрический период.
3. Каждые 100 мс сохраняется строка: время от отключения, последний измеренный период
   и наибольшая абсолютная разность У−N за последние 100 мс. Это сводка, не сырая
   осциллограмма. Память журнала — 360 байт, всего 60 строк.
4. После сообщения **«Выбег записан; команда d — частота и обороты»** отправить d.
   Можно сохранить вывод как CSV. Все данные нужно прислать целиком.

Столбцы: `мс,электрическая_Гц,об_мин,пик_АЦП`. Десятичный разделитель частоты — точка.
Например, 33,33 электрических Гц соответствуют примерно 1000 об/мин при двух парах
полюсов ротора. Параметр ROTOR_PAIRS=2 взят из описания двигателя; если пар другое
число, показание оборотов будет неверным, но электрическая частота останется измеренной.
Формула: `RPM = 60 * электрическая_Гц / ROTOR_PAIRS`.

Столбец пик_АЦП помогает оценить сигнал: один отсчёт — примерно 4,9 мВ на входе АЦП
при опоре 5 В. Это напряжение на делителях, а не непосредственно на обмотках.

Если столбцы частоты и оборотов показывают **нет**, сигнал не измерен или последний
период устарел. Это **не нулевые обороты и не доказательство механической остановки**.
Оценка имеет ограниченную точность из-за последовательного АЦП, шума и малого сигнала
при снижении скорости. Первые строки до двух полных переходов тоже могут быть «нет».
Направление вращения по одной фазе на выбеге не определяется.

Повторная команда s при уже отключённом мосте не стирает журнал и код остановки.
Новый реальный запуск и последующее отключение начинают новую запись.
Если ротор перестал вращаться ещё во время принудительного управления, выбег может
не дать измеряемых периодов — это полезный результат, а не повод подставлять расчётную
скорость поля вместо измеренной скорости ротора.

## Текущий сравнительный опыт после наблюдения срыва

Установлен FINAL_SECTOR_US=20000 вместо 10000: при двух парах полюсов конечная
расчётная скорость поля снижена с 500 до 250 об/мин. Мощность автоматически не повышена.
В начале q должна быть строка **«Конечный сектор, мкс=20000»**.
После прошивки стартовый ШИМ вновь 54; для сравнения с прежними 60 нужен один + в ожидании.
Затем ручку в ноль, немного увеличить и o. Если вращение пропало, сразу s.
После шести секунд выдать d. Пока o не вращает двигатель устойчиво до отключения,
не имеет смысла ослаблять требования захвата обратной связи.

Во время разгона раз в секунду выводится короткая строка вида
`Разгон мкс=40000 ШИМ=60`; на конечной частоте — `Тест мкс=20000 ШИМ=60`.
Записать, при какой строке ротор фактически остановился. Эти значения задаёт программа;
измеренными оборотами они не являются. Вывод разрешён только при достаточном месте
в буфере UART, чтобы не задерживать коммутацию ожиданием передачи.

## Первый запуск и настройка

1. Прошивать с отключёнными 12 В силового моста. Проверить распиновку и перемычку
   нейтрали на D6. Использовать БП с ограничением тока и предохранитель.
2. Запустить при небольшой ручке, записать поведение на позиционировании, разгоне
   и захвате. При сильных рывках или повышенном токе немедленно s.
3. При коде 6 проверить знак и форму ЭДС свободной фазы относительно нейтрали,
   соответствие аналоговых входов фазам. Команда e меняет полярность только если
   её необходимость подтверждается измерениями, а не случайными повторными пусками.
4. Настройки запуска находятся в начале `.ino`: время позиционирования, начальный
   и конечный сектор, начальный ШИМ. Это **новые исходные значения**, не измеренные
   параметры вашего двигателя. Ток при их настройке контролируется аппаратно.
5. DEAD_TIME_US=120 — исходная пауза, не гарантия отсутствия сквозного тока.
   Проверить реальное закрывание ключей по напряжению затвор–исток. Обычные земли
   щупов Rigol подключать только к GND, с учётом заземления БП и PE. Не подключать
   землю щупа к фазе или +12 В. Для плавающего Vgs нужно дифференциальное измерение.

На моторе данный скетч не проверен. Программного ограничения тока нет. Правильный
поиск ЭДС не гарантирует бесшумности шестиступенчатого двигателя. Пуск при вращающемся
от внешнего воздействия роторе не реализован.

## Проверка в облачной среде

```sh
python scripts/build_avr.py firmware/NanoBldcClean/NanoBldcClean.ino
g++ -std=c++17 -Wall -Wextra -Werror -DBLDC_MODEL -DF_CPU=16000000UL -I tests/fake_arduino tests/clean_test.cpp -o /tmp/bldc-clean-test
/tmp/bldc-clean-test
```

Проверены: запрет пуска без нуля ручки, весь путь от старта до непрерывной обратной
связи, изменение мощности, потеря ЭДС, отсутствие захвата, пауза выбега, реверс,
остановка ручкой, автоматическое завершение тестов j/o, пределы пускового ШИМ, медианный фильтр и сравнение времени через переполнение счётчика.
Модель не проверяет физические фронты ключей, шум и динамику реального двигателя.

Проверка измерения выбега отдельной моделью:

```sh
g++ -std=c++17 -Wall -Wextra -Werror -DBLDC_MODEL -DF_CPU=16000000UL -I tests/fake_arduino tests/coast_test.cpp -o /tmp/bldc-coast-test
/tmp/bldc-coast-test
```

Проверены известный сигнал около 33,3 Гц / 1000 об/мин, заполнение 60 строк,
отключённые ключи на протяжении записи, устаревание сигнала и сохранение журнала
при повторной команде остановки. Испытаний на настоящем двигателе не было.
