# Выгрузка CH2/CH3/CH4 Rigol DS1104Z через USB

На приборе пользователя Ultra Sigma успешно ответила на `*IDN?`: модель **DS1104Z**,
прошивка **00.04.04.SP4**. Используется интерфейс USB INSTR через системную VISA.
Экспортёр рассчитан на командную систему семейства Rigol DS1000Z.

## Запуск на Windows

1. Оставить нужную запись на Rigol в **STOP**. CH3 — A1/W, CH4 — D6/N; CH2 — дополнительный измеряемый сигнал.
   **Все три канала должны быть включены до съёмки.** Включение CH2 после STOP
   не создаёт данные отсутствующего канала; потребуется новая запись.
   Сигнал должен быть записан во время вращения, а не только после выключения.
2. Закрыть окно управления прибором и Ultra Sigma, чтобы два приложения не читали
   ответы одного прибора одновременно. Осциллограф оставить включённым и подключённым.
3. Скачать ZIP репозитория и **распаковать в отдельную папку**. Открыть подпапку `scripts`.
4. Запустить двойным щелчком **rigol_export.cmd**. Рядом должен находиться rigol_export.py.
5. Нужен установленный Python 3 с Python Launcher (`py`). Если он отсутствует,
   установите Python для Windows с официального сайта https://www.python.org/downloads/windows/ .
   Нужны Python и Launcher; настройка PATH для запуска через py не обязательна.
6. При отсутствии PyVISA командный файл устанавливает её через pip в выбранный
   Python 3: `py -3 -m pip install "pyvisa>=1.14,<2"`. Системная VISA должна быть
   установлена отдельно; работа Ultra Sigma не гарантирует, что её библиотека
   доступна именно выбранной разрядности Python.
7. После завершения рядом появится папка **rigol_capture_…**. Пришлите файлы
   **rigol_ch2_ch3_ch4.csv** и **metadata.json** из неё.

Окно после выполнения остаётся открытым. При ошибке пришлите весь текст окна.
Особенно важно различать отсутствие Python, отсутствие библиотеки VISA и ошибку
чтения данных прибора. Скрипт не переустанавливает драйверы и не меняет настройки Windows.

## Что сохраняется

По умолчанию CSV содержит `time_s,ch2_V,ch3_V,ch4_V,ch3_minus_ch4_V`. Это общая шкала времени и напряжения,
переведённые из байтов прибора по индивидуальной преамбуле каждого канала:

`U = (BYTE − YORigin − YREFerence) × YINCrement`.

Время: `t = (исходный_индекс − XREFerence) × XINCrement + XORigin`.
Вертикальные смещения каналов учитываются. Делить напряжения повторно на коэффициент
щупа не нужно: используются масштабы, сообщённые самим прибором. При этом настройка
щупов ×10 в меню осциллографа должна соответствовать фактическому переключателю щупа.

Из памяти читаются блоки не больше 200000 байт; в CSV сохраняется не более 200000
равномерно выбранных точек каждого канала. Отбор идёт по общей сетке индексов,
поэтому на границах блоков нет скачка времени или взаимного сдвига каналов.
Фильтрация и усреднение не применяются. При записи около 120 мс это обычно даёт шаг
порядка микросекунды или меньше, что подходит для просмотра ШИМ с периодом около 32 мкс.
Фактический шаг печатается в окне и сохраняется в metadata.json.

Если шаг после отбора больше 2 мкс, программа выводит предупреждение. Тогда можно
выгрузить больше точек через параметр --max-points, учитывая размер итогового файла.

Перед чтением отправляется STOP и проверяется остановленное состояние. Команды RUN,
AUTO SCALE и очистка памяти не используются. Настройки передачи WAV меняются для
чтения RAW/BYTE; они не изменяют уже записанную осциллограмму. Включение/выключение
каналов, временная развёртка, аналоговые масштабы и прошивка Nano не изменяются.

Файл metadata.json содержит идентификацию прибора, VISA-адрес, список каналов, параметры масштабов,
число исходных точек и шаг отбора. Идентификация включает серийный номер прибора.
Новая папка создаётся для каждой выгрузки; существующие результаты не перезаписываются.

## Запуск командой при необходимости

Из папки scripts:

```bat
py -3 rigol_export.py
```

По умолчанию выгружаются каналы **2, 3, 4**, результат — `rigol_ch2_ch3_ch4.csv`.
Для прежней записи, содержащей только CH3/CH4:

```bat
py -3 rigol_export.py --channels 3 4
```

Или передать тот же параметр командному файлу:

```bat
rigol_export.cmd --channels 3 4
```

В этом случае сохраняется прежнее имя `rigol_ch3_ch4.csv`. Разность CH3−CH4 добавляется,
когда выбраны оба канала. В metadata.json сохраняются параметры каждого выбранного
канала и список channels. Масштабы CH2 могут отличаться: его напряжение пересчитывается
по собственной преамбуле. При несовпадении временной сетки хотя бы одного канала
скрипт выдаёт ошибку вместо молчаливого совмещения разных данных.

Скрипт проверяет отображение каналов, но не включает их автоматически. Поэтому
экспортёр не возобновляет RUN и не меняет состав уже записанной осциллограммы.
Укажите вместе с записью, к какой точке подключён CH2, чтобы правильно её трактовать.

При нескольких приборах адрес можно скопировать из Ultra Sigma:

```bat
py -3 rigol_export.py --resource "USB0::0x1AB1::0x04CE::ВАШ_СЕРИЙНЫЙ_НОМЕР::INSTR"
```

Регистр/полное написание адреса лучше копировать точно из программы.
Можно указать путь к совместимой библиотеке через --visa-library, но сначала нужно
узнать, какая VISA установлена. При ошибке разрядности не следует подставлять случайную DLL.

## Проверка без прибора

```sh
python -m unittest discover -s tests -p test_rigol_export.py -v
```

Проверены многоблочная выгрузка, сохранение общей сетки при отборе точек, вертикальное
масштабирование, разность CH3−CH4, выключенный CH2, двухканальный режим, отказ при усечённом ответе и несовпадении времени.
Проверка на настоящем DS1104Z из облачной среды недоступна: USB подключён к компьютеру
пользователя. Совместимость конкретной установленной VISA и ответов прошивки
подтверждается первым реальным запуском, а не этими тестами.
